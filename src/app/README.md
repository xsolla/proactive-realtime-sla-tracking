Route handlers only; the UI is the `sla-tracking` mini-app in `xsolla/mini-apps` (see `specs/2026-10-16-mini-app-split-design.md`). `layout.tsx` stays because Next requires a root layout. `api/sla/pages/*` return the page envelopes the mini-app renders; `dashboard/` is the pure view-model module behind them (`load.ts` reads once per request, `pages.ts` builds the envelope, `view.ts` is the role-neutral view model both roles share). Routes may import feed, alerts, terms and `@/ingestion` (its public entry point only, never `@/ingestion/writer` or `@/ingestion/db`); they read through `data` (reads only). Every route sets `dynamic = "force-dynamic"`, calls `noStore()` and answers `Cache-Control: no-store`.
